# 研途顺利 · 计算机考研助手

面向 **计算机类考研（11408 / 22408）** 的微信小程序，覆盖从择校、备考规划到冲刺复试的全流程。

## 两条核心路径
- **11408**：英语一 + 数学一 + 408 计算机学科专业基础（学硕为主）
- **22408**：英语二 + 数学二 + 408 计算机学科专业基础（专硕为主）

所有内置资源、院校数据、智能分析都按这两条路径自动过滤适配。

## 功能模块
- **院校库**：200+ 招生单位、学硕/专硕齐全，含分档参考区间与官方核实入口；支持冲/稳/保三档智能择校。
- **备考资源库**：40+ 篇离线长文（408 四门速查、算法大题套路、计算题公式、英语/政治模板、复试机试、调剂指南等），支持全文检索与一键存笔记。
- **智能分析引擎**：从学习数据识别黄金时段、周趋势、科目投入失衡与风险预警；样本不足时明确不下结论。
- **AI 助手**：本地规则引擎 + 云端模型降级，覆盖择校/调剂/复试/效率分析/资源检索等意图。
- **番茄钟 / 任务 / 错题 / 卡片 / 模考 / 周报** 等日常备考工具。

## 技术说明
- 原生微信小程序，纯 JavaScript（CommonJS），导入微信开发者工具即跑，无需编译。
- 数据层以 `wx.storage` 为真相源，本地优先；接后端只需替换 services 内部实现。
- 云能力（可选）：`cloudfunctions/ai` + `server/` 提供 AI 代理；需自备 AppID 与云环境，并在 `utils/config.js` 填写 `CLOUD_ENV_ID`。

## 数据诚实性说明
招生计划与复试线以**分档参考区间**呈现，非官方数据，界面均标注来源与核实入口；详情页支持录入真实分数线，录入后以你的数据为准。择校决策请以院校官方公布信息为准。

## 开发
1. 微信开发者工具导入本目录。
2. 在 `project.config.json` 配置你的 AppID（建议与「待办事项」等其它小程序使用**独立 AppID**，避免体验版互相覆盖）。
3. 如需云 AI：开通云环境 → 在 `utils/config.js` 填 `CLOUD_ENV_ID` → 右键 `cloudfunctions/ai` 上传部署。
